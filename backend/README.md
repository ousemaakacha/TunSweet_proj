# Backend TUNISWEET

Express con account cliente verificati via email, amministrazione protetta, catalogo e ordini con pagamento al ritiro.

Dalla root avviare con `npm --prefix backend run dev`
PEr inizializzare l’amministratore con `npm --prefix backend run admin:create`. Non esistono credenziali predefinite.
Leggere il [README principale](../README.md) per configurazione SMTP e Cloudinary, dati, API, sicurezza, calendario e verifiche.
